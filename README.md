## 🚀 Ключевые открытые проекты / Flagship Open-Source Projects

### 1. [🇷🇺 Google AntiGravity 2.0 — 100% Русификатор & MCP Auto-Updater (`antigravity-features-v2`)](https://github.com/WiseYaroslav28/antigravity-features-v2)
> Полная локализация интерфейса агентной среды **Google AntiGravity 2.0** для **Windows 10/11 и macOS** с переключением `EN | RU` за `0 мс` без перезапуска, живым автообновлением через **Model Context Protocol (MCP)** + **Chrome DevTools Protocol (CDP)**, сохранением геометрии окна на 2-м мониторе и исправлением системного трея.

- **Установка в 1 строку (Windows PowerShell):**
  ```powershell
  irm https://raw.githubusercontent.com/WiseYaroslav28/antigravity-features-v2/main/install.ps1 | iex
  ```
- **Установка в 1 строку (macOS Terminal):**
  ```bash
  curl -fsSL https://raw.githubusercontent.com/WiseYaroslav28/antigravity-features-v2/main/install.sh | bash
  ```
- 📺 [**Видеообзор на YouTube**](https://www.youtube.com/shorts/sucYFc3UqpM) • 📖 [**Разбор архитектуры на Хабре**](https://habr.com/ru/articles/1104106/) • 📰 [**Статья на VC.ru**](https://vc.ru/id6168328/3229744-rusifikator-google-antigravity-2-0-avtoobnovleniem-cherez-mcp)

### 2. [🎙️ SINC PRO — Audio Intelligence (`sinc-pro-voice-widget`)](https://github.com/WiseYaroslav28/sinc-pro-voice-widget)
> Легковесный десктопный ИИ-комбайн продуктивности на базе **Rust + Tauri v2** (0% CPU в простое): умная голосовая диктовка с ИИ-форматированием (`Ctrl + Win`), студийная нейросетевая озвучка любого выделенного текста с Web Audio бустером до `200%` (`-14 LUFS`), экранный OCR-переводчик с картинок/видео (`Alt + Q`) и автопереключатель раскладки.
